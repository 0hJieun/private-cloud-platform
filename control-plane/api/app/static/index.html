INSTANCE STATUS

VM 상태 안내

사용 가능
VM과 상태 점검이 모두 정상입니다. 등록한 SSH 키로 접속할 수 있습니다.
생성 중
배치, 디스크 복제, VM 기동, DHCP 주소 할당을 처리하고 있습니다. 잠시 후 새로고침하세요.
상태 확인 중
VM은 만들어졌고 첫 상태 정보가 수집되기를 기다리는 중입니다. 보통 기동 뒤 잠시 내에 바뀝니다.
호스트 연결 끊김
VM이 배치된 compute 노드의 응답을 확인할 수 없습니다. 관리자가 해당 노드를 점검해야 합니다.
VM 응답 없음
compute 노드는 정상이나 VM 내부 상태 점검이 응답하지 않습니다. VM 기동·네트워크 상태를 확인하세요.
생성 실패
생성 작업이 중단됐습니다. 상세 화면의 마지막 오류를 확인한 뒤 다시 요청하거나 관리자에게 문의하세요.
삭제 중
VM과 연결된 디스크·네트워크 자원을 정리하고 있습니다. 완료될 때까지 기다리세요.
생성 완료
이전 정책에서 만들어져 상태 점검 정보가 없는 VM입니다. 새 VM은 자동으로 상태 점검을 적용합니다.
