# Roadmap

## Phase 0 — Lab foundation

- VMware networks and VM settings
- Rocky Linux base installation
- SSH key and hostname policy

## Phase 1 — Manual infrastructure

- control DHCP
- compute libvirt/KVM
- compute OVS bridge
- storage NFS

## Phase 2 — First instance

- image catalog
- qcow2 clone
- cloud-init seed ISO
- DHCP lease and SSH verification

## Phase 3 — Automation

- Ansible roles
- scheduler and resource reservation
- MariaDB state model
- dynamic inventory

## Phase 4 — Operations

- node-exporter
- Prometheus/Grafana
- logs and audit events
- failure tests

## Phase 5 — Extensions

- web administrator page
- GlusterFS
- backup and restore
- optional Ceph experiment
